# Blackjack

This is a lightweight, static Blackjack game built with HTML, CSS, and vanilla JavaScript.

## Play on GitHub Pages

1. Push this repo to GitHub.
2. In the repo, open **Settings → Pages** (it is in the left sidebar under “Code and automation”).
3. Under **Build and deployment**, set:
   - **Source** to “Deploy from a branch”.
   - **Branch** to your default branch (e.g. `main`) and `/ (root)`.
4. Click **Save**, then wait for the green “Your site is live” banner.
5. Open the URL GitHub shows (it will look like `https://<your-username>.github.io/<repo-name>/`).

Once Pages is enabled, the site will serve `index.html` at the root, so you can play directly from that link.

## If you only see “Verified domains”

That’s a different part of the Pages settings. Scroll up on the same Pages screen to find **Build and deployment**. You do **not** need a custom domain to publish the game.
