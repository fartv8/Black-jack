# Blackjack

This is a lightweight, static Blackjack game built with HTML, CSS, and vanilla JavaScript.

## Play on GitHub Pages

1. Push this repo to GitHub.
2. In **Settings → Pages**, set **Source** to your default branch (e.g. `main`) and `/ (root)`.
3. Save, then open the URL GitHub shows (it will look like `https://<your-username>.github.io/<repo-name>/`).

Once Pages is enabled, the site will serve `index.html` at the root, so you can play directly from that link.
