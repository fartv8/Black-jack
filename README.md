# KeebLab

An interactive mechanical keyboard switch sound tester. Type on the virtual keyboard, compare twelve popular switch profiles, and filter the library by linear, tactile, or clicky feel.

## Run locally

Open `index.html` in a modern browser, or serve the folder with:

```bash
python3 -m http.server 8000
```

Sounds are synthesized in the browser with the Web Audio API, so no audio downloads are required.
